ANTES DE COMECAR
- Aceite o convite de colaborador do GitHub (chega por e-mail) do repositorio mariana-collab/luz-emergencia-iot.
- Tenha o Git instalado: https://git-scm.com/download/win
- Esta pasta (Amanda-supabase) tem a subpasta "supabase", que voce vai adicionar ao repositorio.

============================================================
CASO A: voce vai usar o SEU computador
============================================================
Abra o PowerShell e rode, um bloco por vez (troque o e-mail pelo da sua conta do GitHub):

git config --global user.name "Amanda Villar Moura"
git config --global user.email "SEU_EMAIL_DO_GITHUB"

cd "$HOME\Documents"
git clone https://github.com/mariana-collab/luz-emergencia-iot.git
cd luz-emergencia-iot

Copy-Item -Path "$HOME\Downloads\Amanda-supabase\supabase" -Destination ".\" -Recurse -Force
git status

git add supabase/schema.sql
git commit -m "Adiciona schema da tabela leituras no Supabase"
git add supabase/functions/ingest
git commit -m "Adiciona funcao ingest (recebe leituras do EMQX)"
git add supabase/functions/api
git commit -m "Adiciona funcao api (consulta de leituras por device_id)"

git pull
git push

git log --format="%h %an <%ae> %s" -4

(Se a pasta Amanda-supabase nao estiver em Downloads, troque o caminho do Copy-Item pelo real.)
